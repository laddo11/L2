# 🥺 Please Forgive Me, Laddu! ❤️

An interactive, live-animated apology web app built with HTML, CSS, and JavaScript designed to bring a smile and make up after an argument.

## Features
- 💖 **Live Floating Hearts Animation:** Continuous soft romantic heart animations in the background.
- 🏃‍♂️ **Playful "No" Button:** The "No" button playfully dodges the cursor when she tries to click it!
- 🥰 **Interactive Success State:** Shows a sweet success message and triggers a heart burst when she clicks "Forgiven".
